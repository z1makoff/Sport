# Sport
Customizable app for Sport Training

Тренировки на время с личными рекордами: каждый день задача побить свой рекорд хотя бы на секунду.

## Как установить
Каждая сборка ветки `main` публикуется в [Releases](../../releases). Открой последний релиз на телефоне,
скачай `sport.apk` и установи (нужно разрешить установку из неизвестных источников).
Новые версии ставятся поверх старых, данные сохраняются.

## Что внутри
- Kotlin + Jetpack Compose, база Room на телефоне, без интернета.
- Свои тренировки: упражнения, повторы, раунды, отдых между раундами.
- Секундомер с отметкой каждого упражнения, «призрак» рекордной попытки, цель «побей рекорд».
- История попыток, ручной ввод и правка времени.
- Голос и звук, вибрация, экран не гаснет, таймер в уведомлении.

## Сборка
`./gradlew assembleDebug` (нужен Android SDK). Тесты логики: `./gradlew testDebugUnitTest`.
